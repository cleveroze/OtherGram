# NEXORA — симулятор криптотерминала

Бумажный торговый терминал: живые свечи, стакан, спот и фьючерсы, NFT-маркетплейс и перетаскиваемая glass-админка.

Это **не биржа**. Ордера, балансы и NFT существуют только в браузере (`localStorage`).

## Запуск

Откройте `index.html` или поднимите статику:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

## Управление

- Терминал / NFT / Портфель — верхнее меню
- Спот и бессрочные фьючерсы с плечом до 125x
- График: колесо — масштаб, перетаскивание — сдвиг, двойной клик — FIT
- Кнопка из четырёх точек справа внизу открывает админ-панель; панель можно тащить за шапку
